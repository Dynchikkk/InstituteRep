Статические файлы и добавление Bootstrap

Оформление: основной текст — по ширине; код — Consolas 12, по левому краю; скриншоты — по центру.

Цель работы

Подключить статические ресурсы, Bootstrap и стили сайта.

Ход работы

1. Для CSS и изображений использована структура статических файлов приложения: main/static/main/css и main/static/main/img. В шаблоне подключена библиотека тегов static.

2. В layout.html добавлены Bootstrap через CDN и ссылка на собственный main.css. Тег static формирует адрес локального файла; Bootstrap подключён обычным HTML-тегом link.

Ответы на контрольные вопросы

1. Что такое статические файлы?
CSS, JavaScript, изображения и другие ресурсы, выдаваемые без обработки шаблонизатором.

2. Какие типы статических файлов поддерживаются?
Любые файлы: CSS, JS, изображения, шрифты и другие.

3. Как загрузить теги статических файлов?
{% load static %}.

4. Какой тег формирует адрес статического файла?
{% static 'main/css/main.css' %}.

5. Где хранятся статические файлы по умолчанию?
В static установленных приложений; дополнительные папки задаются STATICFILES_DIRS.

6. Что такое Bootstrap?
Библиотека CSS и JavaScript для оформления интерфейсов.

7. Как подключить Bootstrap?
Через link и при необходимости script: с CDN или из локальных статических файлов.

8. Какие компоненты Bootstrap можно использовать?
Сетку, кнопки, формы, меню, карточки, таблицы и другие; интерактивным компонентам нужен JavaScript Bootstrap.

9. Есть ли специальный тег Django для компонентов Bootstrap?
Нет. Используются HTML-разметка и CSS-классы Bootstrap.

10. Что такое CSS?
Язык описания внешнего вида HTML-документа.

11. Как подключить CSS в Django?
Загрузить static и добавить <link rel="stylesheet" href="{% static 'main/css/main.css' %}">.
