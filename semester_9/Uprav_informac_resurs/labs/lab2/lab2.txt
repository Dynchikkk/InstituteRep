Листинг

Файл Команда терминала (изменения данного этапа)

python manage.py startapp main

Файл config/settings.py (изменения данного этапа)

# Дополнить существующий список INSTALLED_APPS:
'main',

Файл main/views.py (изменения данного этапа)

from django.http import HttpResponse


def index(request):
    return HttpResponse('Главная страница магазина настольных игр')


def about(request):
    return HttpResponse('О магазине: здесь можно выбрать настольные игры для семьи и друзей.')

Файл main/urls.py (изменения данного этапа)

from django.urls import path
from . import views

urlpatterns = [
    path('', views.index, name='home'),
    path('about/', views.about, name='about'),
]

Файл config/urls.py (изменения данного этапа)

from django.contrib import admin
from django.urls import include, path

urlpatterns = [
    path('admin/', admin.site.urls),
    path('', include('main.urls')),
]

Вывод

Ответы на контрольные вопросы

1. Как добавить новое приложение?
python manage.py startapp имя_приложения.

2. В каком файле регистрируется приложение?
В settings.py, в списке INSTALLED_APPS.

3. Как добавить URL-маршрут приложения?
Создать urls.py приложения и подключить его через include() в корневом urls.py.

4. Что делает path('posts/best/', include('posts.urls'))?
Передаёт обработку адресов с префиксом posts/best/ маршрутам из posts.urls.

5. Что делает HttpResponse?
Формирует HTTP-ответ с переданным содержимым.
