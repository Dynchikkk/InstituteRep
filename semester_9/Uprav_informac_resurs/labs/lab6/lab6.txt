Листинг

Команды терминала

python manage.py startapp catalog
python manage.py makemigrations catalog
python manage.py migrate
python manage.py createsuperuser

Файл config/settings.py (изменения данного этапа)

# Дополнить INSTALLED_APPS:
'catalog',

LANGUAGE_CODE = 'ru'

Файл catalog/models.py (изменения данного этапа)

from django.db import models
from django.core.validators import MinValueValidator
from django.utils import timezone


class Product(models.Model):
    title = models.CharField('Название', max_length=100)
    short_description = models.CharField('Краткое описание', max_length=250)
    description = models.TextField('Полное описание')
    price = models.DecimalField('Цена', max_digits=10, decimal_places=2, validators=[MinValueValidator(0)])
    created_at = models.DateTimeField('Дата добавления', default=timezone.now)

    def __str__(self):
        return self.title

    class Meta:
        verbose_name = 'Товар'
        verbose_name_plural = 'Товары'

Файл catalog/admin.py (изменения данного этапа)

from django.contrib import admin
from catalog.models import Product

admin.site.register(Product)

Файл config/urls.py (изменения данного этапа)

Ответы на контрольные вопросы

1. Какая база данных используется в Django по умолчанию?
SQLite. Django также поддерживает другие СУБД.

2. Какой класс служит основой моделей таблиц?
django.db.models.Model.

3. Что такое миграции?
Файлы с описанием изменений структуры базы данных.

4. Какие команды создают и применяют миграции?
python manage.py makemigrations и python manage.py migrate.

5. Что такое панель администратора?
Встроенный интерфейс управления зарегистрированными моделями и пользователями.

6. Как создать пользователя для админки?
python manage.py createsuperuser.

7. Где регистрируется модель для админки?
В admin.py приложения.

8. Какой метод регистрирует модель?
admin.site.register(Product).
