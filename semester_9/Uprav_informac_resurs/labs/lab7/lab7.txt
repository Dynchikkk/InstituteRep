Вывод записей из базы данных

Оформление: основной текст — по ширине; код — Consolas 12, по левому краю; скриншоты — по центру.

Цель работы

Выбрать записи через ORM и отобразить их в каталоге.

Ход работы

1. В представление каталога импортирована модель Product. Товары выбираются запросом Product.objects.order_by('title')[:5]: сортируются по названию и ограничиваются первыми пятью записями.

2. QuerySet передаётся в render() под ключом products. В шаблоне if проверяет наличие товаров, а for создаёт карточку для каждой записи. Для пустого каталога предусмотрено отдельное сообщение.

3. В карточке показаны название, краткое описание, цена и дата добавления. Для цены применён floatformat:2, для даты — date. В CSS добавлены оформление карточки и выделение цены.

4. Дополнительно предусмотрены обложка товара и связанные изображения ProductImage. Файлы загружаются через админку; для ImageField установлен Pillow. В каталоге обложка выводится только при наличии файла.

5. Для загрузок заданы MEDIA_URL и MEDIA_ROOT, настроена локальная раздача media при DEBUG=True. Общий CSS перенесён в static/css проекта и подключён через STATICFILES_DIRS. Файл db.sqlite3 и загружаемые media не включаются в репозиторий.

Файл catalog/views.py (изменения данного этапа)

from django.shortcuts import render
from catalog.models import Product

def index(request):
    # Сортируем товары по названию и выбираем первые пять записей.
    products = Product.objects.order_by('title')[:5]
    data = {'products': products}
    return render(request, 'catalog/catalog.html', data)

Файл catalog/models.py — связанные изображения (изменения данного этапа)

class ProductImage(models.Model):
    product = models.ForeignKey(Product, on_delete=models.CASCADE, related_name='images')
    image = models.ImageField('Изображение', upload_to='products/images/')
    caption = models.CharField('Подпись', max_length=150, blank=True)

    def __str__(self):
        return self.caption or f'Изображение товара «{self.product.title}»'

    class Meta:
        verbose_name = 'Изображение товара'
        verbose_name_plural = 'Изображения товара'

Файл catalog/admin.py (изменения данного этапа)

from django.contrib import admin
from catalog.models import Product, ProductImage


# Встроенный редактор галереи на странице товара в админке.
class ProductImageInline(admin.TabularInline):
    model = ProductImage
    extra = 1


class ProductAdmin(admin.ModelAdmin):
    inlines = [ProductImageInline]


admin.site.register(Product, ProductAdmin)

Ответы на контрольные вопросы

1. Какой класс отображает список записей?
ListView. В проекте используется обычная функция представления с QuerySet.

2. Какой метод сортирует записи?
order_by().

3. Какие поля можно передать в order_by()?
Поля модели и поля связанных моделей через __; например title или product__title.

4. Как указать обратную сортировку?
Добавить минус перед именем: order_by('-title').

5. Как выбрать первые десять записей?
Product.objects.all()[:10].
