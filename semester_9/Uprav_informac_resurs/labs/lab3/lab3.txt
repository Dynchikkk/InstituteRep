Листинг

Файл main/views.py (изменения данного этапа)

from django.shortcuts import render


def index(request):
    return render(request, 'main/index.html')


def about(request):
    return render(request, 'main/about.html')

Файл main/templates/main/layout.html (изменения данного этапа)

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>{% block title %}{% endblock %}</title>
</head>
<body>
    <p>Общий layout</p>
    {% block content %}{% endblock %}
    <a href="{% url 'home' %}">Главная</a>
    <a href="{% url 'about' %}">О магазине</a>
</body>
</html>

Файл main/templates/main/index.html (изменения данного этапа)

{% extends 'main/layout.html' %}
{% block title %}Магазин настольных игр{% endblock %}

    <p>Добро пожаловать! Здесь можно выбрать настольные игры для семьи и друзей.</p>
    {% include 'main/test.html' %}

Ответы на контрольные вопросы

1. Как называется шаблонизатор Django?
По умолчанию — Django Template Language (DTL). Jinja2 подключается как отдельный движок.

2. Каково назначение Jinja?
Генерация текста и HTML на основе шаблонов и переданных данных.

3. Где хранятся шаблоны по умолчанию?
В templates установленных приложений при APP_DIRS=True; обычно templates/имя_приложения/.

4. Как вывести переменную контекста?
{{ variable }}.

5. Для чего нужен block content?
Задаёт область содержимого, которую переопределяют дочерние шаблоны.

6. Где определяется block content?
В базовом HTML-шаблоне, например layout.html.

7. Для чего нужна render()?
Обрабатывает шаблон с контекстом и возвращает HTTP-ответ.

8. Какие параметры принимает render()?
Основные: request, template_name и необязательный context; также content_type, status и using.
