Редактирование и удаление записей

Оформление: основной текст — по ширине; код — Consolas 12, по левому краю; скриншоты — по центру.

Цель работы

Добавить изменение и удаление товаров через встроенные классы Django.

Ход работы

1. Созданы ProductUpdateView и ProductDeleteView. Для каждого добавлен URL с идентификатором товара: /catalog/<id>/update/ и /catalog/<id>/delete/. На странице товара размещены кнопки перехода.

Файл catalog/views.py (изменения данного этапа)

from django.urls import reverse_lazy
from django.views.generic import UpdateView, DeleteView
from catalog.forms import ProductForm
from catalog.models import Product, ProductImage

class ProductUpdateView(UpdateView):
    model = Product
    form_class = ProductForm
    template_name = 'catalog/create.html'

    def form_valid(self, form):
        response = super().form_valid(form)
        # Новые картинки дополняют галерею, прежние остаются на месте.
        for image in form.cleaned_data['images']:
            ProductImage.objects.create(product=self.object, image=image)
        return response


# При GET показываем подтверждение, при POST удаляем товар.
class ProductDeleteView(DeleteView):
    model = Product
    template_name = 'catalog/product_delete.html'
    context_object_name = 'product'
    success_url = reverse_lazy('catalog')

    # Адрес страницы товара для перехода после редактирования.
    def get_absolute_url(self):
        return reverse('product_detail', kwargs={'pk': self.pk})

Ответы на контрольные вопросы

1. Какой метод модели удаляет объект?
delete().

2. Как обновить данные объекта модели?
Изменить его атрибуты и вызвать save(). Для обновления QuerySet используется update().

3. Какой метод сохраняет изменения объекта?
save().

4. Какой метод возвращает адрес объекта?
get_absolute_url().

5. Какой атрибут модели указывает URL-шаблон объекта?
Стандартного атрибута для этого нет. Адрес обычно возвращает get_absolute_url() через reverse('product_detail', kwargs={'pk': self.pk}).
