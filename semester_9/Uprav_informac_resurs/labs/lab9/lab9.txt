Лабораторная работа № 9

Динамически изменяемые страницы

Оформление: основной текст — по ширине; код — Consolas 12, по левому краю; скриншоты — по центру.

Цель работы

Создать общий шаблон страницы отдельного товара с выбором записи по URL.

Ход работы

1. В catalog/views.py создан ProductDetailView на основе DetailView. Атрибут model указывает Product, template_name — шаблон страницы, context_object_name — имя product в контексте.

2. В catalog/urls.py добавлен маршрут <int:pk>/. Значение pk берётся из URL и определяет, какой товар получить из базы. Класс подключён через as_view().

3. В product_detail.html выведены название, полное описание, цена, дата и обложка. Блок title содержит product.title, поэтому заголовок вкладки зависит от выбранного товара.

4. Для дополнительных картинок использована существующая галерея: шаблон перебирает product.images.all, выводит миниатюры и выбранное изображение. gallery.js подключается только при наличии картинок.

5. В карточках каталога добавлена кнопка «Подробнее» с product.pk. Она открывает нужную запись; для всех товаров используется один шаблон. Старую статическую страницу шахмат заменяет страница товара из базы.

Листинг

Файл catalog/views.py (изменения данного этапа)

from django.views.generic import DetailView
from catalog.models import Product

class ProductDetailView(DetailView):
    model = Product
    template_name = 'catalog/product_detail.html'
    context_object_name = 'product'

Файл catalog/urls.py (изменения данного этапа)

path('<int:pk>/', views.ProductDetailView.as_view(), name='product_detail'),

Файл catalog/templates/catalog/product_detail.html (изменения данного этапа)

{% extends 'main/layout.html' %}
{% load static %}

{% block title %}{{ product.title }}{% endblock %}

{% block scripts %}
    {% if product.images.exists %}
        <script src="{% static 'main/js/gallery.js' %}" defer></script>
    {% endif %}
{% endblock %}

{% block content %}
    <h2>{{ product.title }}</h2>
    <p>{{ product.short_description }}</p>
    <div>{{ product.description|linebreaks }}</div>
    {% if product.logo %}
        <img class="catalog-image" src="{{ product.logo.url }}" alt="{{ product.title }}">
    {% endif %}
    <p class="product-price">{{ product.price|floatformat:2 }} ₽</p>
    <p><small>Добавлено: {{ product.created_at|date:"d.m.Y H:i" }}</small></p>

    <!-- Используем загруженные картинки товара в общей галерее. -->
    {% with images=product.images.all %}
        {% if images %}
            <h3>Изображения игры</h3>
            <p>Выберите изображение. Наведите курсор на большую картинку, чтобы увеличить её.</p>
            <div class="gallery">
                {% for image in images %}
                    <button type="button" class="image-choice{% if forloop.first %} selected{% endif %}"
                            aria-pressed="{% if forloop.first %}true{% else %}false{% endif %}"
                            aria-label="Показать: {{ image.caption|default:product.title }}">
                        <img src="{{ image.image.url }}" alt="{{ image.caption|default:product.title }}">
                    </button>
                {% endfor %}
            </div>
            {% with first_image=images.0 %}
                <div class="image-preview">
                    <img id="selected-image" class="game-photo" src="{{ first_image.image.url }}"
                         alt="{{ first_image.caption|default:product.title }}" width="320" height="320" tabindex="0">
                </div>
                <p id="image-caption">{{ first_image.caption|default:product.title }}</p>
            {% endwith %}
        {% endif %}
    {% endwith %}

    <a class="btn btn-outline-light" href="{% url 'catalog' %}">Вернуться в каталог</a>
{% endblock %}

Ответы на контрольные вопросы

1. Что такое динамическая страница?
Страница, содержимое которой формируется по данным и параметрам запроса.

2. Какой класс показывает отдельную запись?
DetailView.

3. В каком модуле находится DetailView?
django.views.generic.detail; также доступен через django.views.generic.

4. Какие файлы используются для шаблонов динамических страниц?
Обычно .html с шаблонными конструкциями; движок может формировать и другой текстовый формат.

5. Как указать модель в DetailView?
Атрибутом model, например model = Product.
