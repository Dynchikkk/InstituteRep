Лабораторная работа № 5

Передача данных в шаблоны

Оформление: основной текст — по ширине; код — Consolas 12, по левому краю; скриншоты — по центру.

Цель работы

Передать контекст в шаблоны, использовать условия, циклы и фильтры.

Ход работы

1. В представлении index() подготовлен словарь data с названием страницы, заголовком категорий и списком категорий. Словарь передан третьим аргументом render().

2. В index.html значения выведены через {{ ... }}. Цикл for создаёт список категорий; if проверяет, есть ли данные, иначе показывает сообщение. Фильтр upper переводит заголовок в верхний регистр.

3. Для страницы о магазине подготовлены словарь shop со вложенным details и список advantages. В шаблоне выполнен перебор преимуществ и пар ключ — значение через shop.details.items.

4. Фильтр lower применён к адресу электронной почты. В браузере проверены вывод данных и единое оформление страниц.

Листинг

Файл main/views.py (изменения данного этапа)

from django.shortcuts import render

def index(request):
    # Значения и список для главной страницы.
    data = {
        'title': 'Магазин настольных игр',
        'categories_title': 'Категории игр',
        'categories': ['Семейные', 'Стратегические', 'Кооперативные'],
    }
    return render(request, 'main/index.html', data)


def about(request):
    # Словарь со сведениями о магазине.
    shop = {
        'name': 'Игры',
        'email': 'SHOP@EXAMPLE.COM',
        'details': {
            'Специализация': 'Настольные игры для семьи и друзей',
            'Время работы': 'Ежедневно с 10:00 до 19:00',
        },
    }
    data = {
        'title': 'О магазине',
        'shop': shop,
        'advantages': [
            'Игры для разных возрастов.',
            'Понятные описания и характеристики.',
            'Помощь в выборе игры для семьи или компании.',
        ],
    }
    return render(request, 'main/about.html', data)

Файл main/templates/main/index.html (изменения данного этапа)

{% extends 'main/layout.html' %}

{% block title %}{{ title }}{% endblock %}

        <h3>{{ categories_title|upper }}</h3>

Файл main/templates/main/about.html (изменения данного этапа)

{% extends 'main/layout.html' %}

{% block title %}{{ title }}{% endblock %}

{% block content %}
    <div class="features">
        
        <h1>{{ title }}</h1>
        <p class="page-intro">Наш магазин предлагает настольные игры для семейных вечеров и встреч с друзьями.</p>

        <!-- Маркированный список преимуществ магазина -->
        <h3>Почему выбирают нас</h3>
        <ul>
            {% for advantage in advantages %}
                <li>{{ advantage }}</li>
            {% endfor %}
        </ul>

        <!-- Детали -->
        <h3>Магазин «{{ shop.name }}»</h3>
        <ul>
            {% for label, value in shop.details.items %}
                <li><strong>{{ label }}:</strong> {{ value }}</li>
            {% endfor %}
        </ul>
        
        <!-- Адрес электронной почты в нижнем регистре. -->
        <p>Почта: <a href="mailto:{{ shop.email|lower }}">{{ shop.email|lower }}</a></p>
        <p><a class="btn btn-outline-light" href="{% url 'catalog' %}">Перейти в каталог</a></p>

    </div>
{% endblock %}

Вывод

Данные передаются в шаблоны через контекст; применены if, for и фильтры upper и lower.

Ответы на контрольные вопросы

1. Какая структура передаёт данные из представления в шаблон?
Словарь контекста.

2. Как передать несколько значений по одному ключу?
Поместить под ключом список, кортеж или другой контейнер.

3. Какая функция передаёт данные в шаблон?
render().

4. Как передать данные через render()?
render(request, 'main/index.html', {'title': 'Магазин'}).

5. Как вставить переменную в шаблон?
{{ title }}.

6. Как записать условие if?
{% if items %}Есть данные{% else %}Нет данных{% endif %}.

7. Как записать цикл for?
{% for item in items %}{{ item }}{% endfor %}.

8. Как применить фильтр?
Через |: {{ title|upper }} или {{ value|default:"Нет данных" }}.
