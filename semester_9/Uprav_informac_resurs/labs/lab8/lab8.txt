Лабораторная работа № 8

Форма для добавления записей в базу данных

Оформление: основной текст — по ширине; код — Consolas 12, по левому краю; скриншоты — по центру.

Цель работы

Создать форму добавления товара с проверкой и сохранением данных.

Ход работы

1. В catalog/forms.py создан ProductForm на основе ModelForm. В Meta указаны модель Product, поля и виджеты; через class="form-control" подключено оформление Bootstrap. Для нескольких картинок добавлены отдельный виджет и проверка каждого файла.

2. Созданы маршрут /catalog/create/ и функция create(). При GET она выводит пустую форму, при POST получает request.POST и request.FILES. После is_valid() товар сохраняется через save(), картинки — отдельными записями ProductImage.

3. В create.html добавлены форма POST, enctype для загрузки файлов и csrf_token. Поля выводятся циклом. Ошибки каждого поля отображаются через field.errors; общие ошибки — через form.non_field_errors.

Файл catalog/forms.py (изменения данного этапа)

from django import forms
from catalog.models import Product


# Разрешаем выбирать несколько файлов 
class MultipleImageInput(forms.ClearableFileInput):
    allow_multiple_selected = True


# Проверяем каждую картинку.
class MultipleImageField(forms.ImageField):
    def clean(self, data, initial=None):
        clean_image = super().clean
        if isinstance(data, (list, tuple)):
            return [clean_image(image, initial) for image in data]
        image = clean_image(data, initial)
        return [image] if image else []


class ProductForm(forms.ModelForm):
    images = MultipleImageField(
        label='Картинки товара',
        required=False,
        widget=MultipleImageInput(attrs={'class': 'form-control', 'accept': 'image/*'}),
        help_text='Необязательно. Можно выбрать несколько изображений сразу.',
    )

    class Meta:
        model = Product
        fields = ['title', 'short_description', 'description', 'price', 'logo', 'images', 'created_at']
        widgets = {
            'title': forms.TextInput(attrs={'class': 'form-control'}),
            'short_description': forms.TextInput(attrs={'class': 'form-control'}),
            'description': forms.Textarea(attrs={'class': 'form-control', 'rows': 4}),
            'price': forms.NumberInput(attrs={'class': 'form-control', 'min': 0, 'step': '0.01'}),
            'logo': forms.ClearableFileInput(attrs={'class': 'form-control', 'accept': 'image/*'}),
            'created_at': forms.DateTimeInput(
                format='%Y-%m-%dT%H:%M',
                attrs={'class': 'form-control', 'type': 'datetime-local'},
            ),
        }
        help_texts = {'logo': 'Необязательно. Можно загрузить изображение товара.'}

Файл catalog/views.py (изменения данного этапа)

from django.shortcuts import redirect, render
from catalog.forms import ProductForm
from catalog.models import Product, ProductImage

def create(request):
    if request.method == 'POST':
        # Получаем значения полей и загруженный файл.
        form = ProductForm(request.POST, request.FILES)
        if form.is_valid():
            product = form.save()
            # Каждую картинку сохраняем отдельной записью, связанной с товаром.
            for image in form.cleaned_data['images']:
                ProductImage.objects.create(product=product, image=image)
            return redirect('catalog')
    else:
        form = ProductForm()

    # При ошибках возвращаем заполненную форму с пояснениями.
    return render(request, 'catalog/create.html', {'form': form})

Ответы на контрольные вопросы

1. Какой модуль используется для форм?
django.forms.

2. Какой класс используется для базовой формы?
forms.Form; для формы на основе модели — forms.ModelForm.

3. Как определяются поля формы?
Атрибутами класса формы; в ModelForm набор полей модели задаётся Meta.fields. Отдельного метода для этого нет.

4. Как указать модель формы в Meta?
Через атрибут model вложенного класса Meta; Meta не является методом.

5. Как задать поля модели в форме?
Через атрибут fields вложенного класса Meta.

6. Какой HTML-тег создаёт форму?
<form>.

7. Какой метод используется для отправки данных формы?
В этой работе — POST; файлы дополнительно передаются через request.FILES.

8. Как добавить CSRF-токен?
{% csrf_token %} внутри формы.
