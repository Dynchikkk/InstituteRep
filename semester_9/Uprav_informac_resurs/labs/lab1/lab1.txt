Цель работы

Создать проект Django, изучить структуру и запустить локальный сервер.

Ход работы

1. Установлен Python 3.14, для разработки выбран Visual Studio Code. В редакторе открыт каталог boardgame_shop.

2. Создано виртуальное окружение .venv и активировано в терминале PowerShell. В окружение установлен Django, проверен путь к используемому интерпретатору.

4. Применены начальные миграции, создан файл db.sqlite3. Запущен сервер разработки; по адресу http://127.0.0.1:8000/ открылась стартовая страница Django.

Листинг

Команды PowerShell

py -3.14 --version
py -3.14 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -c "import sys; print(sys.executable)"
python -m pip install Django
python -m django startproject config .
python manage.py migrate
python manage.py runserver

Вывод

Создан проект Django с изолированным окружением. Изучена структура проекта, запущен локальный сервер.

Ответы на контрольные вопросы

1. Для какого языка Django является фреймворком?
Python.

2. Какой пакетный менеджер есть в Python?
pip.

3. Какая команда устанавливает Django?
python -m pip install Django.

4. Какая команда запускает локальный сервер?
python manage.py runserver.

5. Какая команда создаёт новый проект?
django-admin startproject config или python -m django startproject config .
