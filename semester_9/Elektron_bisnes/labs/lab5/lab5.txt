Цель работы

Изучить JavaScript и реализовать интерактивные элементы сайта.

Ход работы

1. Добавлены два JavaScript-файла: main.js для общего графического меню и gallery.js для галереи. Скрипты подключены с defer, поэтому выполняются после разбора HTML. gallery.js подключается только на странице с галереей.

2. На странице «Шахматы» размещены три кнопки с миниатюрами. По нажатию обработчик selectImage() переносит адрес и альтернативный текст выбранной картинки в большое изображение. Подпись обновляется через textContent, а выбранная миниатюра выделяется рамкой.

3. Для приближения изображения исходные width и height считываются из HTML. Функция setImageScale() умножает их на коэффициент 1.25. При уходе курсора масштаб возвращается к 1; те же действия доступны при получении и потере клавиатурного фокуса.

4. В общий шаблон добавлено горизонтальное меню с иконками. При наведении на пункт функция showArrow() показывает стрелку, а hideArrow() скрывает её при уходе курсора. Обработчики подключены через addEventListener().

5. В CSS заданы расположение миниатюр через Flexbox, рамка выбранной кнопки и положение стрелки. Под большой картинкой оставлен запас высоты, чтобы увеличение не сдвигало таблицу характеристик.

Файл main.js

// Показываем и скрываем стрелку у ссылки, на которой произошло событие.
function showArrow(event) {
    const arrow = event.currentTarget.querySelector('.menu-arrow');
    arrow.hidden = false;
}

function hideArrow(event) {
    const arrow = event.currentTarget.querySelector('.menu-arrow');
    arrow.hidden = true;
}

// Подключаем обработчики общего графического меню.
function initGraphicMenu() {
    const menuLinks = document.querySelectorAll('.graphic-menu a');

    for (const link of menuLinks) {
        link.addEventListener('mouseenter', showArrow);
        link.addEventListener('mouseleave', hideArrow);
        link.addEventListener('focus', showArrow);
        link.addEventListener('blur', hideArrow);
    }
}

initGraphicMenu();


Файл gallery.js

// Находим элементы галереи и запоминаем исходные размеры из HTML.
const selectedImage = document.getElementById('selected-image');
const choices = document.querySelectorAll('.image-choice');
const caption = document.getElementById('image-caption');
const originalWidth = Number(selectedImage.getAttribute('width'));
const originalHeight = Number(selectedImage.getAttribute('height'));
const zoomScale = 1.25;

// Масштабируем относительно исходных размеров, сохраняя пропорции.
function setImageScale(scale) {
    selectedImage.width = Math.round(originalWidth * scale);
    selectedImage.height = Math.round(originalHeight * scale);
}

function enlargeImage() { setImageScale(zoomScale); }
function resetImageSize() { setImageScale(1); }

// Показываем картинку из нажатой кнопки и обновляем подпись.
function selectImage(event) {
    const choice = event.currentTarget;
    const thumbnail = choice.querySelector('img');
    selectedImage.src = thumbnail.src;
    selectedImage.alt = thumbnail.alt;
    caption.textContent = thumbnail.alt;
    resetImageSize();

    // Переносим выделение на выбранную миниатюру.
    for (const button of choices) {
        button.classList.remove('selected');
        button.setAttribute('aria-pressed', 'false');
    }
    choice.classList.add('selected');
    choice.setAttribute('aria-pressed', 'true');
}

// Связываем нажатие, наведение и фокус с нужными функциями.
function initGallery() {
    for (const choice of choices) {
        choice.addEventListener('click', selectImage);
    }

    selectedImage.addEventListener('mouseenter', enlargeImage);
    selectedImage.addEventListener('mouseleave', resetImageSize);
    selectedImage.addEventListener('focus', enlargeImage);
    selectedImage.addEventListener('blur', resetImageSize);
}

initGallery();

Ответы на контрольные вопросы

1. Что представляет собой язык сценариев?

Язык для выполнения команд, обрабатываемых средой исполнения. В браузере JavaScript управляет поведением страницы.

2. Чем характеризуется объект HTML?

Свойствами, методами и событиями.

3. Что такое свойства, события и методы?

Свойства — данные объекта; события — происходящие действия; методы — функции объекта.

4. Какие события JavaScript вы знаете?

click, mouseenter, mouseleave, input, change, submit, focus, blur, keydown, load.

5. Что такое параметры обработки событий?

Аргументы обработчика. Обычно передаётся event с данными о событии и элементе-источнике.

6. Как описывается процедура JavaScript?

Через функцию: function имя(параметры) { действия; }.

7. Охарактеризуйте объектную модель документа.

DOM представляет документ деревом объектов, доступных для чтения и изменения через JavaScript.

8. Какие технологии используются для динамических эффектов?

HTML задаёт структуру, CSS — оформление и переходы, JavaScript и DOM — изменение элементов и обработку событий.

9. В чём различие серверного и клиентского программирования?

Клиентский код выполняется в браузере и управляет интерфейсом. Серверный обрабатывает запросы, проверяет данные и работает с базой.
