Листинг

Файл main/templates/main/layout.html (фрагмент)

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>{% block title %}{% endblock %}</title>
    <!-- Внешний CSS -->
    <link rel="stylesheet" href="{% static 'css/main.css' %}">
    <!-- Скрипты выполняются после разбора HTML. -->
    <script src="{% static 'main/js/main.js' %}" defer></script>
    {% block scripts %}{% endblock %}

Файл catalog/templates/catalog/create.html (фрагмент)

<!-- enctype нужен для передачи файла вместе с текстовыми полями. -->
    <form method="post" enctype="multipart/form-data" class="product-form">
        {% csrf_token %}

        {% if form.non_field_errors %}
            <div class="form-errors">{{ form.non_field_errors }}</div>
        {% endif %}

        {% for field in form %}
            <div class="mb-3">
                <label for="{{ field.id_for_label }}" class="form-label">{{ field.label }}</label>
                {{ field }}
                {% if field.help_text %}
                    <small>{{ field.help_text }}</small>
                {% endif %}
                {% if field.errors %}
                    <div class="form-errors">{{ field.errors }}</div>
                {% endif %}
            </div>
        {% endfor %}

        <button type="submit" class="btn btn-warning">{% if object %}Сохранить изменения{% else %}Добавить товар{% endif %}</button>
        {% if object %}
            <a href="{{ object.get_absolute_url }}" class="btn btn-outline-light">Отмена</a>
        {% else %}
            <a href="{% url 'catalog' %}" class="btn btn-outline-light">Отмена</a>
        {% endif %}
    </form>

Ответы на контрольные вопросы

1. Какие новые элементы и теги добавлены в HTML5?

Семантические header, footer, nav, main, section, article, aside; мультимедиа audio, video, canvas; элементы details и summary.

2. Укажите основные конструкции HTML5.

Объявление <!DOCTYPE html>, корневой html, секции head и body; элементы, атрибуты и комментарии.

3. Приведите базовую структуру документа HTML5.

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Название</title>
</head>
<body>
    <main>Содержимое</main>
</body>
</html>

4. Чем отличаются блочные элементы от строчных?

В обычном потоке блочные элементы начинаются с новой строки; строчные располагаются внутри строки. Поведение отображения изменяется свойством display.

5. В чём особенность гибкой блочной модели?

Flexbox распределяет место между элементами, управляет их выравниванием, порядком, размерами и переносом.

6. Какие новые возможности HTML5 расширили функциональность JavaScript?

Работа с canvas, аудио и видео, хранением данных, фоновыми задачами и другими API веб-платформы.

7. Какие API рассматриваются вместе с HTML5?

Canvas, Web Storage, Geolocation, Web Workers, History, Drag and Drop, API аудио и видео. Часть из них стандартизована отдельно от HTML.
