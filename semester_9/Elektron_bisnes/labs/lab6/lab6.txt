Лабораторная работа № 6

Подготовка графических и текстовых материалов для размещения на web-сайте

Оформление: основной текст — по ширине; код — Consolas 12, по левому краю; скриншоты — по центру.

Цель работы

Подготовить текстовые и графические элементы и разместить их на странице.

Ход работы

1. Создана отдельная страница «Варианты кнопок». В боковое меню добавлена ссылка для перехода на неё. Все примеры выполнены тегом button с type="button", без отправки формы.

2. Размещены три варианта: кнопка с текстом, кнопка с изображением и кнопка с текстом и изображением. Для графики использован общий SVG-логотип настольных игр; размер и выравнивание заданы классом .button-icon.

3. По образцу задания внутри четвёртой кнопки размещены таблица из двух строк и двух столбцов и горизонтальная линия hr. Для каждой ячейки задан отдельный класс с цветом фона.

4. В main.css добавлены стили кнопок, изображения, таблицы и линии. Кнопки получили общие отступы, границу и скругление; таблица — фиксированную ширину и размеры ячеек. Для кнопок без видимой текстовой подписи указаны aria-label.

Листинг

Файл buttons.html

{% extends 'main/layout.html' %}
{% load static %}

{% block title %}Варианты кнопок{% endblock %}

{% block content %}
    <h2>Варианты кнопок</h2>

    <!-- Кнопка с обычным текстом. -->
    <h3>Кнопка с текстом</h3>
    <button type="button" class="example-button">Выбрать игру</button>

    <!-- Кнопка, содержимое которой состоит из изображения. -->
    <h3>Кнопка с картинкой</h3>
    <button type="button" class="example-button" aria-label="Выбрать игру">
        <img class="button-icon" src="{% static 'main/img/board-games-logo.svg' %}" alt="">
    </button>

    <!-- Изображение и текст находятся внутри одной кнопки. -->
    <h3>Кнопка с текстом и картинкой</h3>
    <button type="button" class="example-button">
        <img class="button-icon" src="{% static 'main/img/board-games-logo.svg' %}" alt="">
        Выбрать игру
    </button>

    <!-- Таблица из двух строк и двух столбцов и горизонтальная линия внутри кнопки. -->
    <h3>Кнопка с таблицей</h3>
    <button type="button" class="example-button" aria-label="Цветная таблица">
        <table class="button-table" role="presentation">
            <tbody>
                <tr>
                    <td class="cell-red">1</td>
                    <td class="cell-yellow">2</td>
                </tr>
                <tr>
                    <td class="cell-green">3</td>
                    <td class="cell-blue">4</td>
                </tr>
            </tbody>
        </table>
        <hr class="button-rule">
    </button>
{% endblock %}

Ответы на контрольные вопросы

1. Какие макеты сайта наиболее распространены?

С навигацией слева, справа, в трёх столбцах или горизонтально.

2. Что такое навигация сайта?

Система ссылок и элементов для перехода между страницами и разделами.

3. Что учитывать при создании навигации?

Понятные названия, логичную структуру, единое расположение и доступность с клавиатуры.

4. Как подбирается цветовая схема сайта?

По тематике и аудитории; выбираются основной, фоновый и акцентный цвета с достаточным контрастом.

5. Какие редакторы удобны для создания логотипа?

Векторные редакторы: Inkscape, Adobe Illustrator, CorelDRAW.

6. Как уменьшить картинку для сайта?

Уменьшить разрешение, выбрать подходящий формат и сжать файл. Изменение width и height в HTML само по себе не уменьшает файл.

7. Зачем выписывать синонимы по теме проекта?

Для подбора поисковых запросов, заголовков и текстов сайта.

8. Что включает принцип AIDA?

Attention — внимание, Interest — интерес, Desire — желание, Action — действие.

9. Какие приёмы привлекают внимание к тексту или картинке?

Контраст, размер, цвет, свободное пространство, расположение и визуальные указатели.

Для дополнения отчёта

Кнопка с настоящей таблицей повторяет образец методички. Такая вложенность не соответствует модели содержимого button в HTML5; при проверке валидатором это нужно учитывать.
