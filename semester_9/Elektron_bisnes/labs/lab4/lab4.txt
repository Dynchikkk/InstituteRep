Лабораторная работа № 4

Каскадные таблицы стилей

Оформление: основной текст — по ширине; код — Consolas 12, по левому краю; скриншоты — по центру.

Цель работы

Изучить способы подключения CSS и оформить страницы сайта.

Ход работы

1. К сайту подключены Bootstrap и внешний файл main.css. Содержимое страниц разделено на боковую панель aside и основной блок main. Для фона выбраны тёмные цвета, для ссылок и акцентов — жёлтый.

2. Применены три способа задания CSS: атрибут style в index.html, блок style в layout.html и внешний main.css. В исходниках сохранены примеры всех способов; в рабочем проекте собственные стили объединены во внешнем файле.

Страницы получили единое оформление. Применены три способа подключения CSS, классы, идентификаторы, псевдоклассы, фильтры и медиаправила.

Ответы на контрольные вопросы

1. Что представляет собой стиль и к каким элементам он применяется?

Стиль — набор CSS-свойств. Применяется к HTML-элементам, выбранным селектором.

2. Для чего используется стилевое оформление?

Для задания цветов, шрифтов, размеров, отступов и расположения элементов.

3. В чём смысл использования CSS?

Отделить оформление от HTML и обеспечить единый вид страниц.

4. Каковы правила записи определения стиля CSS?

Селектор { свойство: значение; }. Например: p { color: white; }.

5. Какие способы задания стилей существуют?

Атрибут style, блок <style> и внешний файл .css.

6. Чем различаются внедрённый, встроенный и связанный стили?

Локальный стиль задаётся атрибутом style, встроенный в документ — тегом <style>, связанный — внешним файлом через <link>.

7. Как оформляется отдельный CSS-файл?

Правила записываются в файл с расширением .css без тегов <style>.

8. Для чего подключают внешнюю таблицу стилей?

Для повторного использования общего оформления на нескольких страницах.

9. Какой тег подключает внешнюю таблицу стилей и где его размещают?

<link rel="stylesheet" href="main.css"> в секции head.

10. Что такое селектор?

Часть CSS-правила, определяющая элементы, к которым оно применяется.

11. Для чего нужны классы и псевдоклассы?

Классы объединяют элементы по оформлению; псевдоклассы выбирают их по состоянию или положению.

12. В чём заключается группировка стилей?

Несколько селекторов перечисляются через запятую и получают общий набор свойств.

13. В чём выражается наследование стилей?

Некоторые свойства родителя, например color и font-family, передаются дочерним элементам.
